
تطوير صفحة الفواتير المحفوظة

تم تطوير هذا الإصدار (0.1.3) للتالي: 

# تطوير صفحة الفواتير المحفوظة، بإضافة:

## إضافة شريط تمرير احترافي
للجداول الطويلة:
```
Scrollbar
```

## إضافة زر تعديل أسفل الجدول بجانب الأزرار 

## دعم النقر المزدوج على الفاتورة؛ بحيث يؤدي إلى:
```
Double Click
→ فتح التعديل مباشرة
```

## دعم تعديل الأصناف داخل جدول الأصناف، بدلاً من حذف الصنف وإعادة إدخاله.
## إعادة ترقيم الجدول تلقائياً بعد الحذف والتعديل.
## إضافة زر "نسخ الفاتورة" لإنشاء فاتورة جديدة اعتماداً على فاتورة سابقة.
## يمكن إضافة تحسينات صغيرة مكملة:
✔ تمييز الصف عند مرور الفأرة (Hover Effect).
✔ دعم زر Enter لفتح التعديل.
✔ دعم زر Delete لحذف الفاتورة المحددة.
✔ إظهار عدد الفواتير المعروضة بعد التصفية.
