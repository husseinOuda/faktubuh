
# نظام لإدارة الفواتير

## ✅ النظام يحتوي على:

### 1. إدارة العملاء

* إضافة / تعديل / حذف عميل
* حفظ في قاعدة بيانات

### 2. إدارة الفواتير

* إنشاء فاتورة
* إضافة خدمات متعددة
* ترقيم تلقائي
* ربطها بعميل

### 3. تصدير PDF احترافي

* شعار
* تنسيق مرتب
* إجمالي + تاريخ

### 4. قاعدة بيانات

* باستخدام SQLite (خفيفة وسريعة)

### 5. واجهة احترافية

* باستخدام `customtkinter`
