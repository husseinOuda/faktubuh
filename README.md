
# نظام لإدارة الفواتير

## ✅ النظام يحتوي على:

### 1. إدارة العملاء

* إضافة / تعديل / حذف عميل
* حفظ في قاعدة بيانات

### 2. إدارة الفواتير

* إنشاء فاتورة
* إضافة خدمات متعددة
* ترقيم تلقائي
* ربطها بعميل

### 3. تصدير PDF احترافي

* شعار
* تنسيق مرتب
* إجمالي + تاريخ

### 4. قاعدة بيانات

* باستخدام SQLite (خفيفة وسريعة)

### 5. واجهة احترافية

* باستخدام `customtkinter`

# 🆕 الإصدار 0.1.6 — المركز المالي

صفحة **«إدارة الفواتير»** صارت مركزاً مالياً بتبويبات، وأُضيف زر **«📈 المالية»** في الشريط الجانبي يفتح اللوحة مباشرة:

| التبويب | الوظيفة |
|---|---|
| 📂 الفواتير المحفوظة | كما كانت + عمودا **المحصّل** و**المتبقي** + زر **💰 سند قبض** |
| 🧾 سندات القبض | إصدار/تعديل/إلغاء/حذف، ربط بفاتورة أو دفعة على الحساب، PDF، تصدير Excel |
| 💸 سندات الصرف | إصدار سندات الدفع، ربطها بمصروف أو دفعة مستقلة، PDF، تصدير Excel |
| 📉 المصروفات | تسجيل وتصنيف المصروفات، متابعة المسدد/المتبقي، دفع فوري، إدارة التصنيفات |
| 📈 لوحة التحكم المالية | مؤشرات، رسم شهري، توزيع المصروفات، أكبر المدينين، آخر الحركات |

## قواعد العمل
- **الترقيم التلقائي**: `RC-2026-0001` (قبض) · `PV-2026-0001` (صرف) · `EX-2026-0001` (مصروف) — يبدأ كل عام من 0001.
- **سند القبض ↔ الفاتورة**: لا يتجاوز المبلغ المتبقي على الفاتورة. عند اكتمال التحصيل تتحول الفاتورة تلقائياً إلى **مدفوعة**، وترجع **غير مدفوعة** إن أُلغي سند أو حُذف فنقص المحصّل. الفواتير التي حدّدتها مدفوعة يدوياً لا تتأثر.
- **سند الصرف ↔ المصروف**: لا يتجاوز المبلغ المتبقي على المصروف. حالة المصروف (غير مسدد / جزئي / مسدد) تُحسب من سنداته الفعّالة.
- **الإلغاء بدل الحذف**: السند الملغى يبقى للأثر ولا يدخل في الحسابات، ويمكن إعادة تفعيله.
- **حماية البيانات**: لا يُحذف عميل لديه سندات، ولا فاتورة مرتبطة بسندات، ولا مصروف له سندات، ولا تصنيف مستخدم.
- **PDF السندات**: بنفس هوية الفاتورة، مع المبلغ **رقماً وكتابةً بالعربية**، وملخص الفاتورة/المصروف، والختم والتوقيع، وعلامة مائية للملغى.

## تعريفات اللوحة المالية
- **صافي الربح** = المبيعات (فواتير غير ملغاة) − المصروفات (غير الملغاة).
- **صافي النقدية** = المقبوضات − المدفوعات (سندات فعّالة).
- **ذمم العملاء** = المتبقي على الفواتير غير المسددة. **المستحقات** = المتبقي على المصروفات. (كلاهما على كل الفترات.)
- **دفعة مستقلة** (سند صرف بلا مصروف) تدخل في المدفوعات/النقدية ولا تدخل في المصروفات/الربح.
