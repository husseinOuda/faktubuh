
# نظام لإدارة الفواتير

## ✅ النظام يحتوي على:

### 1. إدارة العملاء

* إضافة / تعديل / حذف عميل
* حفظ في قاعدة بيانات

### 2. إدارة الفواتير

* إنشاء فاتورة
* إضافة خدمات متعددة
* ترقيم تلقائي
* ربطها بعميل

### 3. تصدير PDF احترافي

* شعار
* تنسيق مرتب
* إجمالي + تاريخ

### 4. قاعدة بيانات

* باستخدام SQLite (خفيفة وسريعة)

### 5. واجهة احترافية

* باستخدام `customtkinter`

# 🆕 الإصدار 0.1.5 — تحسين جدول الفواتير

- **جدول الأصناف وجدول الفواتير المحفوظة**: رأس بلون الهوية، صفوف متناوبة، تحديد وتمييز واضح، أعمدة من اليمين لليسار، محاذاة منظمة، وعمود `#` للترقيم.
- **شريط معلومات** تحت جدول الأصناف (عدد الأصناف + مجموع الكميات).
- **المعاينة** صارت تعرض ملف الـ PDF الحقيقي بنفس التصميم النهائي.
- **PDF احترافي (A4)**: ترويسة بالشعار وبيانات الجهة، صندوقا العميل والفاتورة، جدول يشبه Excel، ملخص مالي، ملاحظات، ختم وتوقيع، تذييل بترقيم الصفحات ورمز QR، وعلامة مائية للفواتير الملغاة.

## تخصيص الهوية
- بيانات الجهة (الهاتف، البريد، العنوان، الرقم الضريبي، نص الشكر، اسم المُصدِر): `COMPANY` في `theme.py` (الحقول الفارغة لا تُطبع).
- الألوان: `BRAND_NAVY` و`BRAND_BLUE` وما يليها في `theme.py`.
- الختم والتوقيع: ضع `assets/stamp.png` و`assets/signature.png` (خلفية شفافة يفضّل). وإن لم يوجدا يُرسم ختم تلقائي ويبقى خط التوقيع فارغاً.
